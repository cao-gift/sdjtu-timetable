FAQ · 常见疑问

你可能关心的问题

会获取或上传我的交院账号密码吗？

不会。登录仅在你手机本地通过 WebView 直连学校官方 WebVPN（wwebvpn.sdjtu.edu.cn）。若主动启用「自动登录」，账号密码会通过 Android Keystore AES-256-GCM 硬件密钥加密保存在本机私有目录且不参与云备份，随时可点「忘记账号密码」彻底删除。

在宿舍外或使用手机流量能同步吗？

可以。应用内置交院 WebVPN 官方入口，校内 Wi-Fi 和校外移动网络都能直接同步课表、成绩、培养方案、考试安排与实时空教室。同步后除实时空教室外均可离线查看。

安装时提示「未知来源」或纯净模式拦截？

这是安卓系统对非商店 APK 的常规提示。确认从本官网（lvlv.freeblock.cn）或 GitHub Releases 下载并核对下方 SHA-256 后，按系统提示继续安装即可。独立包名 app.lvlv.timetable 可与旧版共存。

教室名称太长或周次不对怎么调整？

在「设置 → 课表设置」顶部可一键「校准周次」；下方「地点简化」会自动提取高频校区与教学楼前缀，点一下即可隐藏并实时预览简化效果。

教务页面变动导致自动同步失败怎么办？

在查询页点击「在教务中定位」，手动点开教务目标菜单看到结果后，再点击「读取此页」即可完成解析；若仍有问题可导出脱敏诊断包并通过邮箱反馈。

是否免费？iOS 与鸿蒙手机支持吗？

完全免费且遵循 GPL-3.0 协议开源，无广告与商业统计 SDK（详见 隐私声明）。当前支持 Android 7.0+（鸿蒙 4 及以下兼容运行），原生 iOS 与鸿蒙端规划开发中。
