驴驴课表隐私政策

应用名称：驴驴课表 · 包名：app.lvlv.timetable · 更新与生效日期：2026 年 11 月 26 日

核心承诺：「驴驴课表」是由学生个人开发维护的非官方校园课表工具。本应用无独立注册账号、无自建云端服务器、不收集或上传您的学籍与个人数据、不接入任何商业广告或行为统计 SDK。您同步的课表、成绩、培养方案、考试安排、作业待办与可选的加密自动登录凭据均仅保存在您本机设备中，您可随时查看、导出或一键清空。

01我们如何收集和使用您的个人信息

本应用严格遵循「合法、正当、必要、最小化」原则。除您主动触发以下具体功能外，本应用不会在后台主动采集您的任何个人信息：

  • 校园教务同步（课表、成绩、培养方案、考试安排、空教室）：当您点击登录或同步时，应用仅在您手机本地通过 WebView 与山东交通学院官方统一门户（wwebvpn.sdjtu.edu.cn）及教务系统页面直接通信。解析后的课表、成绩、培养方案与考试安排仅保存于本机应用私有目录，查空教室结果仅在内存中实时展示、不写入本地缓存。开发者无法获取、也不存储您的任何学号、姓名或教务数据。
  • 统一门户自动登录凭据（可选，默认关闭）：仅在您主动前往「设置 → 教务账号 → 管理自动登录」输入并明示同意保存后，应用才会使用 Android Keystore 生成的 AES-256-GCM 硬件级密钥对账号密码进行加密，并仅存放于本机 no_backup 私有目录中。该凭据仅用于本机自动填充学校官方认证表单，绝不会发送至学校官方域名以外的任何服务器，您可随时点击「忘记账号密码」彻底删除。
  • 课块下雨提示（可选）：仅在您手动开启「课块下雨提示」并授予粗略位置权限后，应用通过系统网络定位获取约 1 公里级粗略经纬度，仅用于向开放气象接口（Open-Meteo）查询未来数天对应上课时段的降雨概率。本应用不申请精确定位权限，不记录您的历史位置轨迹。
  • 课程作业附图与扫码分享（可选）：当您主动为作业添加照片、或扫描同学的脱敏课表二维码时，仅在本地处理图像与二维码内容，图片仅存于本机应用私有目录。课表分享码仅包含课程名、教室、上课时间与周次，不包含学号、姓名及教师信息。
  • 应用内检查更新：仅拉取官网静态更新清单（lvlv.freeblock.cn/latest.json 及备用镜像）对比版本号与安装包 SHA-256 校验值，不上传设备唯一标识（如 IMEI、OAID、MAC 地址、Android ID 等）。
  • 诊断包导出（主动触发）：仅在您遇到同步异常并主动点击「导出诊断包」时在本地生成脱敏日志压缩包，导出前会自动剔除账号密码、Cookie、会话令牌、学号、姓名、邮箱与 URL 参数，且仅由您自行决定是否保存或发送给开发者。

03第三方服务与 SDK 说明

本应用未接入任何第三方广告 SDK、数据分析/统计埋点 SDK、推送 SDK 或社交登录 SDK，不存在向第三方共享、转让或公开披露您个人信息的情形。

  • 学校官方门户（*.sdjtu.edu.cn）：由用户自行登录访问，用于获取本人教务数据。
  • Open-Meteo 气象服务（api.open-meteo.com）：仅在用户开启「课块下雨提示」并授权定位时发送粗略经纬度（保留约两位小数精度）以获取天气预报，不附带任何个人或设备身份信息。
  • 本地开源组件：应用内集成的 AndroidX、Material Components 与 ZXing 二维码库均为纯本地运行组件，不发起联网数据上报。

04数据的本地存储与安全保护

  • 存储地点：您的所有课表、成绩、培养方案、考试安排、同学课表与作业待办均仅保存在您设备的应用私有存储目录内，不会上传至开发者服务器。
  • 安全加密：可选的统一门户自动登录凭据采用 Android Keystore 托管的 AES-256-GCM 密钥加密存储，且标记为不参与系统云备份（no_backup）；全量本地备份文件导出时亦严格排除任何账号密码、Cookie 与会话令牌。
  • 存储期限：数据仅在您使用本应用期间留存于本机。当您执行清空本地数据或卸载本应用时，相关本地数据将被彻底清除。

05您的隐私权利与管理方式

依据《中华人民共和国个人信息保护法》及相关法规，您对本机存储的个人信息享有以下完整权利，并可直接在应用内自主行使：

  • 查阅与复制权：您可随时在应用内查阅已同步的课表、成绩、培养方案、考试安排与作业待办，并可通过「设置 → 课表与上课时间 → 备份课表」或「设置 → 通用设置 → 高级选项 → 导出全量备份」导出标准 JSON 数据副本。
  • 更正与补充权：您可在课表页直接修改或删改课程信息，在「设置 → 教务账号 → 管理自动登录」中随时更新凭据，或在「课表设置」中校准学期日期与上课时间。
  • 删除与清空权：
    • 删除自动登录凭据：进入「设置 → 教务账号 → 管理自动登录 → 忘记账号密码」，立即删除加密凭据与密钥。
    • 一键清空全部本地数据：进入「设置 → 通用设置 → 高级选项 → 清空本地数据」，彻底清除本机全部课表、成绩、培养方案、考试安排、作业待办、上课时间配置及自动登录凭据。
  • 撤回同意与权限管理：您可随时在应用内关闭「课块下雨提示」「上课提醒」「成绩更新通知」等功能开关，或在手机系统「设置 → 应用管理 → 驴驴课表 → 权限」中随时撤回位置、相机、日历、通知等任意权限授权。
  • 账号注销说明：本应用不提供也不强制注册自有账号，无云端用户档案。当您执行「清空本地数据」或直接卸载本应用后，即视为终止使用并彻底删除所有本机留存数据。
  • 响应时限与投诉反馈：如您对隐私保护有任何疑问、建议或投诉，可通过下方开发者邮箱联系我们，我们将在收到核验请求后的 15 个工作日 内予以回复与处理。

06未成年人保护、政策更新与联系我们

未成年人保护：本应用主要面向在校大学生提供校园课表辅助服务。若您为未满 18 周岁的未成年人，请在监护人指导下阅读本声明并使用本应用。

政策更新：如因功能调整或法律法规变化需要修订本隐私声明，我们将在本页面及时更新并标注生效日期；若涉及权限或数据处理方式重大变更，将在应用内以醒目方式告知。
